This project focuses on building a web application designed to store and manage critical medical and user data. The system securely tracks data for patient records, medical records, user accounts, registered hospitals, and match details. It allows authorized users to perform core data management actions, including creating, editing, and deleting patient records. Additionally, the system handles administrative tasks, such as enabling or disabling user accounts and registering new hospitals.
